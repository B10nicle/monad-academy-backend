## Goal

Production hardening for execution sandbox.

## Requirements

- No network access

- CPU limits
- Read-only filesystem
- Automatic cleanup

## Acceptance Criteria

- Sandbox isolated
- Resource exhaustion prevented

- feature implemented end-to-end
